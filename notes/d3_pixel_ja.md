# D3 手先カメラの画素感度：モータの床の下で何が見えるか（2026-10-12）
問い：センサなしの QDD グリッパのモータが感じられる力（床）の下で、手先カメラ（Arducam B0495）は把持の力を見られるか。コードは sim_demos/floor/mjcf_floor.py
（床の物理を載せた公式 MJCF）と floor/pixel_sens.py（画素感度）、図は floor/pixel_sens.png。実機の数（縁の傾き・ゆらぎ・摩擦）は floor_ja.md F2〜F5-2 の測定値で、ここでは測り直していない。印：【測】実データで測った、【計】計算・シミュレーション、【仮】仮定。確からしさは 高 / 中 / 低。

## 結論
1. **公式 MJCF のカメラでは実映像を再現できない**【計、高】。camera_wrist_left（fovy 66、ピンホール）を 1920×1200 で描き padcal と同じ規則で内縁を取ると、縁の傾きは実機の 5.1〜6.2 倍
   （外側の指＝左縁）と 2.4〜3.2 倍（内側の指＝右縁）。左右の非対称は sim 2.1〜2.3 倍、実機 0.98〜1.05 倍。保持角で物体なしの開きは 223〜347 px（640 幅。実機 A は 117 px）。写像 2 通り ×
   比 n 1 / 1.25 の 4 組のどれでも合わない（表 1）。カメラは調整していない。推測（未検証、低）：sim のカメラは外側の指の軸と同じ y = 18.2 mm にあり、実機の左右対称はカメラが顎の対称面の近くにあることを示唆する。
2. よって px/mm は**実機の縁の傾きから校正した 1.55〜2.06 px/mm**（640 幅、接触点で閉じる向き）を主に使う【計、中】。sim の値（640 換算 3.3〜10.4）は 1.6〜6.7 倍大きく、参考値にとどまる。
3. **床の下で見える物体の変形は、柔らかい物のものだけ**【計、中。k は仮定】。片縁の F_cam = ゆらぎ × 2k ÷ (px/mm)。640 幅・個体 A のゆらぎ（0.5〜0.7 px）で、イチゴ（0.5〜1 N/mm）0.25〜0.90 N、
   ブドウ（P1-3 の 0.13〜0.42）0.06〜0.38 N、ブルーベリー 0.65〜1.19 N、ブドウ（2 N/mm）0.98〜1.80 N で、どれも A の床 3〜5 N の 0.6 倍以下（小さいもので 1/80）。チェリー（5 N/mm）は 2.45〜4.50 N で床とほぼ同じ。ブドウ（14）と
   リンゴ（20）は 6.9〜17.9 N で床より上。**剛体（≥ 100 N/mm）は F_cam が約 49 N 以上で保持力 27〜44 N を超え、見えない。剛体ではモータの床がすべて。**
4. 個体 B の床（0.3〜0.7 N）の下で、640 幅・B のゆらぎ（1〜2 px）で見えるのは P1-3 のブドウと柔らかいイチゴの一部だけ。1920 幅でゆらぎが同じ px なら【仮】イチゴ 0.16〜1.03 N、ブルーベリー
   0.43〜1.36 N まで下がる。ただし B のゆらぎは主に遅い漂い（F5-2）で、物の実際の動きなら 1920 幅では px で 2.5〜3 倍になり利得は消える。B は 1920 幅での実測が要る。
5. **パッドの圧縮は床の下では見えない**【計と測、中】。F5（A、32 把持の中央値）では着地から保持まで 12.8〜20.8 N 増えても、開きは両縁で 0.56 px しか動かない。全部をパッドの圧縮とみても
   1 パッド 138〜181 µm で k_pad ≥ 71〜151 N/mm。k_pad = 71 でも片縁の F_cam は 640 幅で ≥ 17 N、1920 幅【仮】で ≥ 5.7 N と、A の床 3〜5 N より上。
6. 剛いグリッパ＋普通の手先カメラで見えるのは**物体の**変形（感度 ∝ 1/k_物体）。指の柔らかさで力を読む先行研究（Sources）とは仕組みが違い、視覚で力を読むこと自体の新しさは主張しない。

## 方法
- mjcf_floor.py：公式 openarm_bimanual.xml（v2）を MjSpec で読み、メモリ上でだけ変える。finger_joint1 の frictionloss（A 0.6、B 0.15 Nm。入力であって結果ではない）、kp 16 / kv 0.3、
  手先カメラ 1920×1200（fovy 66 のまま）、noslip_iterations 10、CAN の量子化（位置 16 bit、速度とトルク 12 bit）。自己試験は物体なしの閉じと 40 mm の剛い箱の把持（表 4）。
- pixel_sens.py (a)：指だけを θ 0〜45° に置き、セグメンテーション画像の行 700〜800（640×480 の行 280〜320）で padcal の規則（中心から外へ 3 px 続けて指に入る最初の位置、行の中央値）で内縁を取る。
  写像 i は縦横別に縮める（x/3、y/2.5）、写像 ii は中央 1600×1200 を切り出して 0.4 倍。実機の傾き（A：q −43〜−23 の 11 区間・5980 コマ、B：8 区間・2796 コマ）と比べる。
  (b)：20×20 mm の箱を顎の間に置き、閉じる向きの幅 10〜60 mm で指が触れる角 θ_c を mj_geomDistance の二分法で出す。接触面の中心を射影して閉じる向き 1 mm あたりの px（x 成分）、幅 20 mm の
  中での変化、視線と面の角 α、mj_ray での見え方を出し、描画でも確かめる（箱を片側 2 mm 縮め、指を新しい θ_c に置く）。(c)：S は物体 (px/mm)/(2k)（k は圧縮の合計で定義、P1-3 と同じ）、
  パッド (px/mm)/k_pad。F_cam = ゆらぎ ÷ S（片縁。両縁の開きなら √2 倍よい）。実機校正の px/mm（640 幅）＝ 実機の縁の傾き 2.51〜2.63 px/モータ deg × n（1〜1.25）÷ sim の運動学での
  閉じ量 1.60〜1.62 mm/指 deg（r_c 92.7 mm）。1920 幅はその 2.5 倍（写像 ii）〜3 倍（写像 i）。
- モータの床（片指、F = nτ/(2r)、r 60〜97 mm、n = 1）【測った τ からの計算】：A の閉じる向きの摩擦 0.60〜0.68 Nm → 3.1〜5.7 N。B の動摩擦 0.15〜0.19 → 0.77〜1.58 N、押されて止まったときの
  p50 0.04〜0.12 → 0.21〜1.00 N。把持内のばらつき A 0.066 → 0.34〜0.55 N、B 0.018 → 0.09〜0.15 N。トルクの 1 刻み 0.0049 → 0.025〜0.041 N。判定には課題の床（A 3〜5 N、B 0.3〜0.7 N）を
  使った。B の 0.3〜0.7 N はどれとも一致せず、押されて止まったときの p50 の範囲に収まる。

## 仮定と確からしさ
- 物体の k と幅【仮、低〜中】：イチゴ 0.5 / 1、ブドウ 2 / 14、チェリー 5、リンゴ 20 は課題の値。ブドウ 0.13〜0.42 とブルーベリー 1.33 は P1-3 で文献から計算した値で、ブドウは出どころで 5〜100 倍
  違うので両方を載せた。幅 10〜60 mm も割り当てた値で、実機の立方体の寸法は不明。1920 幅のゆらぎ【仮、低】は 640 幅と同じ px と置いた（遅い漂いが mm の動きなら px で 2.5〜3 倍に増える）。
- 実機校正の px/mm【計、中】：縁の傾きは開き側 q −43〜−23（その範囲で直線）で測り、保持角 −19.7 まで一定と仮定。mm への換算は sim の運動学で、縁の行に写るのが r 60 mm の点なら px/mm は 1.5 倍、
  F_cam は 2/3。幅によらずほぼ同じ値なのは 1 本の傾きから出したため。比 n【仮】は不明：A の開端 −55.7° を可動域 45° に収めるには n ≥ 1.24、B の −45.1° は n = 1 と合う（零点のずれとは未分離）。
- k_pad の下限【計と測、中】：F5 の 0.56 px を全部パッドの圧縮とみた上限から。暗い縁がパッドの面であること、45 mm 立方体での px/mm（1.55〜2.03）を仮定。パッドの素材は公式文書になく、MJCF の
  _02 メッシュは pale_silver の材質でパッドではない。目安の k = EA/t（A 100 mm²、t 2 mm）は Shore 30A で約 57、TPU 95A で約 2200 N/mm【仮、低】。
- レンズ【計】：fovy 66 のピンホールは 1200 行で f = 924 px、水平 92.2°・対角 101.6°。データシートは水平 82°・対角 95°、EFL 3.6 mm（AR0234 の画素 3.0 µm なら【仮】f ≈ 1200 px）で、1 つの
  ピンホールでは両方を満たせない（実機のレンズは歪む）。中心付近の px/mm は sim から ±30 % 程度しか決まらない。公式 XML のカメラ解像度は 960×600。
- 接触点は平らな面どうしの接触で、mj_geomDistance の点は面上のどこでもありうる。接触面の中心を使い、幅 20 mm での差（±4 %）を表 2 に入れた。物体の圧縮は箱を縮める幾何で与え（MuJoCo の剛体）、
  曲面の果物では輪郭が同じだけ動くと仮定した。noslip_iterations 10 は公式（0）から変えた。0 では指が frictionloss を這い抜け、2 deg/s で 0.11 Nm しか要らない。

## sim では分からないこと
1. 実機のカメラの位置・向き・レンズの歪み（公式 MJCF は合わない、表 1）。1920×1200 でのゆらぎ（実機映像がない。既定のピントは 2 m〜∞ で、接触までの距離は 63〜79 mm【計】）。
2. パッドの素材と剛性、構造のたわみ（sim は 7.5〜8 倍硬い）、接触後にエンコーダが何を見るか。物体の本当の剛性と寸法、曲面での輪郭の動き、回転やすべり、照明・影・圧縮ノイズ、比 n。

## 再現
```
cd sim_demos   # 実機の校正区間と F5 の数は padcal.py の出力（padcal.npz、padcal_newarm.npz）から pixel_sens.py に定数で入れてある
nice -n 10 python -u -W ignore floor/mjcf_floor.py --unit A --selftest   # --unit B、--damping 0、--noslip 0、--side right も
nice -n 10 python -u -W ignore floor/pixel_sens.py --table <scratchpad>/d3/pixel_sens_table.txt   # 約 3 秒。図は floor/pixel_sens.png
```
